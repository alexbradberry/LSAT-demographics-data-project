I wanted to be able to demonstrate my ability to dive into data, so I created this project as if I was going to present it in a meeting.
I first gathered data from LSAT.org and their data and research section, which is readily available publicly. The 2026 admin year is not over yet, so I was only able to use older data.
I picked 2024 and 2025 demographics as well as narrowing the scope down to schools in NC and SC. (There are well over 150 law colleges out there!).
I entered the data and calculated things such as percentage differences and I even dove into the areas that the Universities were located in to get a sense of why the acceptance rate may have changed.
I took that data and put it into a PowerPoint in an easily digestible format and then moved on to using SQL.
I created two main tables and ran prompts that would return the same values that I had already calculated in Excel, just to show that I am able to also SQL to my advantage.
